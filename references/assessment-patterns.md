# Assessment patterns

Use this reference for assessment creation, branching, confidence ratings, remediation, or feedback design.

## Standard item

Include:

1. Objective or skill measured
2. Stem
3. Options
4. Correct answer
5. Correct-answer rationale
6. Distractor-specific feedback when the misconception matters

Keep the stem complete without relying on the options. Make options parallel in grammar and similar in length.

## Confidence-rated item

After the answer, ask:

`How confident are you? Low / Medium / High`

| Accuracy | Confidence | Response |
|---|---|---|
| Correct | High | Reinforce and advance |
| Correct | Low/Medium | Explain reasoning; offer brief practice |
| Incorrect | Low | Teach the missing concept; retry with scaffold |
| Incorrect | High | Confront misconception with evidence; require targeted retry |

Do not award mastery from confidence alone. Treat repeated high-confidence errors as priority remediation.

## Branching assessment

Use branches only when choices reveal different reasoning, risk, or skill gaps. Each branch needs:

- a decision with sufficient evidence;
- a consequence tied to the choice;
- coaching tied to the learner’s reasoning;
- a route back to the assessed objective.

Avoid branches that differ only cosmetically or punish learners with long dead ends.

## Scenario scoring

Prefer a transparent rubric:

- Critical decision: 2 points
- Acceptable but incomplete: 1 point
- Unsafe or ineffective: 0 points

Define mastery before writing items. Weight points by consequence, not text length or artificial difficulty.

## Feedback formula

`Result → Why → Rule or criterion → Next action`

Example:

`Not yet. The response shares customer data without consent. Confirm authorization first, then use the approved channel.`
