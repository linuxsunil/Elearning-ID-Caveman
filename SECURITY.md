# Security

E-learning ID Caveman is an instruction-only skill. It does not require an account, backend, telemetry or API key.

## Safe use

- Do not paste confidential learner, client, employee or SME data into an AI system without authorization.
- Do not store API keys in Storyline variables, JavaScript, course files or repository content.
- Review generated policy, compliance, legal and safety content with an authorized subject-matter expert.
- Test browser APIs and external integrations in the target LMS environment.
- Treat generated QA findings as unverified until reproduced.

Report a repository security concern privately through GitHub's security reporting feature when available.
